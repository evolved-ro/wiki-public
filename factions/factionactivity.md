# 📜 Regulamentul Activitatii in Factiuni: Tot ce trebuie sa stii

Daca faci parte dintr-o factiune, este esential sa stii ca activitatea ta este monitorizata. **Raportul de activitate** este modul nostru de a ne asigura ca toata lumea participa si mentine factiunea activa.

---

## ⚠️ Regulile de Baza si Sanctiunile

| Regula | Detalii | Sanctiune |
| :--- | :--- | :--- |
| **Obligatoriu** | Raportul de activitate trebuie completat de toti membrii. | **Raport Warn** (expira in 14 zile) |
| **Toleranta Zero** | Membrii de **Rank 1** care nu completeaza raportul. | **Uninvite automat** (excludere din factiune) |

---

## 📈 Sistemul de Rank Up in Cadrul Factiunii

Sistemul de promovare este bazat pe loialitate si timp. Promovarea la rangul urmator se acorda **automat** dupa implinirea unui numar prestabilit de zile ca membru activ.

| Rank | Conditie de Obtinere |
| :---: | :--- |
| **1** | Primit automat la intrarea in factiune. |
| **2** | Dupa **7 de zile** implinite de la intrarea in factiune. |
| **3** | Dupa **7 de zile** implinite de la promovarea la Rank 2. |
| **4** | Dupa **14 de zile** implinite de la promovarea la Rank 3. |
| **5** | Dupa **14 de zile** implinite de la promovarea la Rank 4. |
| **6 (Co-Leader)** | Promovare directa acordata de catre Lider. |
| **7 (Leader)** | Ales de catre staff-ul serverului, pe baza unor criterii prestabilite. |

## 📊 Puncte de Activitate (Activity Points) Necesare

**Punctele de activitate (XP)** reprezinta numarul total de actiuni specifice factiunii care trebuie atinse, pe langa orele jucate.

### Structura Punctelor de Activitate

Punctele de activitate sunt constituite din 2 parti:

1.  **Actiunile Efective (XP):** Minim **50%** din totalul punctelor.
2.  **Ore Jucate (XP):** Maxim **50%** din totalul punctelor.

### Exemplu (Pentru Rank 1 - 15000 XP)

* Poti avea **7500 XP** din actiuni efective si **7500 XP** din ore jucate.
* Poti avea **12500 XP** din actiuni efective si **2500 XP** din ore jucate.

> [!WARNING] Nu poti obtine mai mult de **50%** din numarul total de XP din ore jucate (in cazul de mai sus, maxim **7500 XP**).

### Total XP Necesare pe Rank (Indiferent de Factiune)

| Rank | Puncte Activitate Necesare |
| :---: | :---: |
| **1** | 15000 XP |
| **2** | 12500 XP |
| **3** | 10000 XP |
| **4** | 7500 XP |
| **5** | 5000 XP |
