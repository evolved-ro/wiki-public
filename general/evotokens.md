# 🪙 EV Tokens
## 📌 Info General

**EV Token** este currency-ul special care poate fi obtinut in joc **exclusiv** prin lucrarea la job-uri.

### 💰 In ce Consta?

Acest sistem este gandit pentru a recompensa jucatorii activi.

* **Proprietati:** Este un **item de inventar** (deci este tradable) si cantareste **0,01 KG / unitate**.
* **Obtinere:** EV Tokens **nu se pot obtine prin donatii** sau alte metode, ci doar muncind.

> [!TIP]
> Sistemul este gandit ca **5 EV Tokens** sa fie echivalentul, in medie, a **1 ora lucrata** la un job.

## ⚙️ Cum Obtii EV Tokens? (Sanse de Drop)

Sansele de a primi un EV Token difera in functie de actiunea specifica a fiecarui job:

| Job | Actiune Specifica | Sansa de a primi 1 EV Token |
| :--- | :--- | :---: |
| **Farmer** | Per tura (Tractor) | 20% |
| **Farmer** | Per tura (Combina/Mower) | 10% |
| **Farmer** | Per vaca (hranita) | 5% |
| **Hunter** | Per animal vanat (fara whistle) | 20% |
| **Hunter** | Per animal vanat (cu whistle) | 4.15% |
| **Fish** | Per peste prins | 3.35% |
| **Truck** | Per cursa finalizata | 33.35% |
| **Miner** | Per click (in mina) | 0.1% |
| **SGR** | Per ghena de gunoi cautata | 20% |
