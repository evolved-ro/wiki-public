Scopul acestei pagini de [WIKI](wiki.evolved.ro) este acela de a diminua intrebarile de pe server ce sunt puse prin chat-ul de ajutor ``/n``, dar si pentru a oferi informatiile esentiale jucatorilor legate de sistemele de pe server.

## Cand a luat nastere proiectul?

Proiectul a luat nastere oficial pe data de 4 noiembrie 2024, cand a fost infiintat serverul de [DISCORD](discord.gg/evolved), insa la acest server se lucreaza de mai mult timp.

## Ce mod de joc este?

Serverul nostru combina elementele clasice de **RPG** de pe comunitatea de SA:MP din Romania cu elemente din viata reala, dar **nu** este un server Roleplay. Modul de joc ofera complexitate si autenticitate jucatorilor nostri.

## Care este cel mai profitabil job de pe server?

Castigul joburilor a fost realizat in asa fel incat, la o ora lucrata, sa se ajunga la acelasi castig indiferent de job-ul practicat.

Pe serverul nostru exista 3 tipuri de job-uri:
**Freelance**, **Hire** si **Passive**.

Job-urile de tip **Freelance**: [FISH](https://wiki.evolved.ro/jobs/freelance/fisherman), [HUNTER](https://wiki.evolved.ro/jobs/freelance/hunter), [MINER](https://wiki.evolved.ro/jobs/freelance/miner), [SGR](https://wiki.evolved.ro/jobs/freelance/sgr),[TAXI](https://wiki.evolved.ro/jobs/freelance/taxi_permit).

Job-urile de tip **Hire**: [TRUCKER](https://wiki.evolved.ro/jobs/hire/trucker), [FARMER](https://wiki.evolved.ro/jobs/hire/farmer).

Job-urile de tip **Passive**: [LIVESTOCK](https://wiki.evolved.ro/jobs/passive/livestock).
