# Regulamentul News Reporters

## Ce Face un News Reporter?

News Reporters se ocupa cu acordarea de **anunturi** (roleplay, gratuite si de promovare) si cu **interviuri**.

* **Anunturi Roleplay:** Informeaza jucatorii despre intamplarile legate de joc.
* **Anunturi Gratuite (AG):** Anunturi date in intervalul **x:50 - x:59** de catre reporterii care participa la sesiune.
* **Anunturi de Promovare:** Informeaza despre promovarea in rank (mai mare de 3) a unui jucator intr-o factiune, promovarea la o functie pe server etc.

---

## 1. Reguli Generale si Sancțiuni

### 1.1. Incalcari de Disciplina si Limbaj

* Membrii factiunii trebuie sa respecte **Regulamentul General al Serverului**. Incalcarea unei reguli poate fi sanctionata cu **FW/Uninvite**, pe langa sanctiunile serverului.
* Limbajul vulgar / insultele se sanctioneaza cu **AV, FW** sau **Uninvite**, in functie de situatie.
    * **Injuriile si jignirile grave** se sanctioneaza cu **FW**. Injuriile grave repetate sunt **Uninvite** direct.
    * **Jignirile usoare** ('n00b-ul drq', 'mars', 'esti prost/destept/fraier') se sanctioneaza cu **AV** sau **FW**.
    * Limbajul vulgar asupra **Liderului si a membrilor** se sanctioneaza aspru, la decizia liderului.
* **Spam-ul** pe chatul `/f` este sanctionat cu **AV, FW** sau **Uninvite**, in functie de gravitate.
* Trebuie sa respectati liderul & subliderul si sa faceti ce vi se spune; in caz contrar, riscati sanctiuni.
* **Deathmatch-ul (DM) aiurea** este sanctionat cu **FW** sau **Uninvite**, in functie de gravitate.
* Este interzis sa folositi **masinile factiunii in scopuri personale** (**FW**).
* **Injuriile/jignirile folosind /news** se sanctioneaza cu **Uninvite cu FP**, posibil si **Ban**.

### 1.2. Reguli Activitate

* **Rank 1:** Nu-si termina raportul de activitate -> **Uninvite automat cu FP**, indiferent de motiv.
* **Rank 2+:** Avertisment la primul raport incomplet, cu obligatia de a recupera punctele in urmatorul raport.
    * Avertismentele expira dupa **20 zile**. Daca un membru cu avertisment nu isi termina urmatorul raport, primeste **Uninvite fara FP**.
* Nu se mai pot depune **cereri de inactivitate**.
* Playerii ce nu s-au mai logat de **3 zile** in factiune nu mai primesc uninvite de la lideri.



### 1.3. Reclamatii Factiuni

* Liderul poate respinge reclamatiile care **nu respecta modelul** sau **contin jigniri**.
    * Reclamatiile cu jigniri atrag **Suspend 1-7 zile** pe panel.
* Subliderul poate raspunde la reclamatii cu acordul liderului, dar **liderul va fi sanctionat** pentru greseli.

## 2. Reguli Anunturi si Interviuri

### 2.1. Amenzi (Greseli Minore)

Se sanctioneaza cu **Amenda** (valoarea in Regulamentul Intern):
* Scrierea gresita a unui nume de jucator/masina/numar de telefon/anunt/interviu.
* Omiterea unui semn de punctuatie.
* Folosirea caps-lock-ului in exces intr-un anunt/interviu (eventual FW).
* Greseli minore (spatiu aiurea/dublu, cuvinte fara rost cu litera mare).

### 2.2. Faction Warn (FW)

| Abatere | Detalii |
| :--- | :--- |
| **Anunt Aiurea** | Daca anuntul este total aiurea (e.g., `/news am gresit ba, scuze; /news numerele pe /f`). |
| **Anunt Interzis** | Vinderea vehiculelor `rent`, materiale, droguri, inchirieri masini/case/business-uri, targuri, **promovarea altor factiuni** (e.g., X ofera licente, Y este la dispozitia dumneavoastra). |
| **Emoticoane/Prescurtari** | Folosirea oricarui tip de emoticon sau prescurtare intr-un anunt/interviu. |
| **Anunt Personal** | Plasarea unui anunt personal. |
| **Anunt Afara AG** | Orice anunt in afara de cele gratuite in intervalul **x:50 - x:59**. |
| **Anunt in Interviu** | Orice tip de anunt plasat intr-un interviu. |
| **Anunt Prea Devreme** | Orice tip de anunt plasat in intervalul **x:00 - x:02**. |
| **Omisiune Numar Tel.** | Omiterea unui numar de telefon intr-un anunt (in special cele gratuite). |
| **Nerespectare Rank Sup.** | Ironii/tupeu fata de lider/colider (**FW** sau **Demitere**). |
| **Telefon Inchis AG** | Inchiderea telefonului (`/turn off`) in timpul anunturilor gratuite (valabil doar pentru cei din sesiune). |
| **Neorganizare AG** | Neorganizarea echipei sau neindeplinirea cerintelor (start/continuare/stop). |
| **Stop AG Dupa Payday** | Postarea stopului anunturilor gratuite dupa Payday. |
| **Interval RP/Promovare** | Nerespectarea intervalului de **2 minute** intre anunturile roleplay/promovare (Amenda daca diferenta este de cateva secunde, FW daca > 30s). |
| **Certuri / Droguri** | Certuri pe chatul factiunii (**FW** sau **Demitere**). Purtarea drogurilor. |
| **Neplata Amenda** | Neplata unei amenzi intr-un interval de **24 de ore**. |
| **Taxa Interviu Gresita** | Cererea unei sume mai mari/mici decat cea setata pentru interviu (**FW**). Taxa interviu de la colegi (**AV**, eventual **FW**). |
| **Interviu Cu Level Mic** | Interviu cu un player ce detine sub **level 10**. |
| **Interviu Repetat** | Acelasi reporter ia interviu aceluiasi jucator in decurs de **30 zile**. |
| **Greseli Interviu** | Scrierea gresita in interviu (cuvinte gen: test, da etc.). |
| **Anunt RP Gresit** | Anunt RP gresit (e.g., soarele rasare la 21:00) (**AV** la prima, **FW** la a doua). |

### 2.3. Demitere (Abuz)

* **Anunt Aiurea (Abuz de Functie):** Se sanctioneaza cu **Demitere** cand este abuz de functie (e.g., `/news am valoare ba, sunt mare bastan, rifa da magie; /news cu injurii/jigniri`).

### 2.4. Reguli Interviu Public (Live)

| Regula | Timp/Conditie | Sancțiune |
| :--- | :--- | :--- |
| **Program Live Saptamana** | Luni - Vineri: 9:00 - 00:00. | Folosirea /live in afara intervalului: **FW** sau **Uninvite**. |
| **Program Live Weekend** | Sambata - Duminica: 9:00 - 1:00. | Folosirea /live in afara intervalului: **FW** sau **Uninvite**. |
| **Timp Raspuns Live** | Asteptare minim **5 secunde** dupa raspunsul intervievatului. | La 3 greseli intr-un live: **AV**. |
| **Spam AG** | 5 anunturi in 3 secunde cu binder. | **AV**, la urmatoarea abatere **FW**. |
| **Dovada Reguli/Greseli** | Dovezile cu regulile prezentate intervievatului si greselile acestuia se pastreaza **minim 24 de ore**. | Lipsa dovezilor: **AV** (prima), **FW** (a doua). |

### 2.5. Intrebari din Public (/question)

* **Acceptare Intrebari:** Min. **8** intrebari, Max. **10** intrebari. (**FW** pentru nerespectare).
* **Structura Interviu:**
    1.  3 intrebari standard (alese de reporter).
    2.  5 intrebari interviu (alese de intervievat sau reporter).
    3.  8-10 intrebari din public.
* **Interviu pe Ora:** Poate fi doar **un interviu pe ora**. Incepe maxim la **x:10**.
    * Al doilea interviu intr-o ora: **FW**. Incepere interviu dupa x:10: **Amenda**.
* **Intrebari Interzise:** Intrebarile scrise in batjocura, cu continut interzis/intim/sexual, reclame directe/indirecte, sau cu multe greseli gramaticale.
    * **Sancțiune:** **AV, FW** sau **Uninvite** direct, in functie de gravitate.

## 3. Responsabilitati Reporteri in Functie de Rank

| Rank | Interviuri Permise | Anunturi |
| :--- | :--- | :--- |
| **Rank 1** | Nu poate da interviu | Toate tipurile de anunturi |
| **Rank 2** | Max. 1 persoana | Toate tipurile de anunturi |
| **Rank 3** | Max. 2 persoane | Toate tipurile de anunturi |
| **Rank 4** | Max. 2 persoane | Toate tipurile de anunturi |
| **Rank 5** | Max. 3 persoane | Toate tipurile de anunturi |
* Anunturile de promovare se pun la raport de la orice rank.
