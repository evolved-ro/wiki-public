# 🏦 Bank
## 📌 Info General

Banca este locul unde fiecare jucator isi poate depozita, transfera, verifica si retrage banii pe care ii are.

### 📍 Locatie si Acces

* **Localizare:** Poti gasi banci in orasele principale.
* **GPS:** Foloseste comanda ``/gps`` -> ``Businesses`` -> ``Bank``.

---

## 💻 Comenzi si Administrare

Comenzile pe care le poti folosi in interiorul bancii sunt urmatoarele:

| Comanda | Functie |
| :--- | :--- |
| **`/withdraw <suma>`** | Retragi o suma de bani din banca. |
| **`/deposit <suma>`** | Depozitezi o suma de bani in banca. |
| **`/balance`** | Verifici balanta pe care o ai in banca. |
| **`/transfer <id jucator> <suma>`** | Transferi o suma de bani catre un anumit jucator. |

> [!TIP]
> Poti verifica balanta bancara (banii din banca) si folosind comanda generala ``/stats``.
